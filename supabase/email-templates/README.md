# Correos de MtiGo! en español

Supabase → **Authentication → Emails → Templates**. Para cada plantilla: pega el **Asunto**, borra el cuerpo actual,
pega el contenido del archivo (botón "Copy raw file" en GitHub) y haz clic en **Save**.

| Plantilla en Supabase | Asunto | Archivo |
|---|---|---|
| Confirm signup | `Confirma tu cuenta de MtiGo!` | [confirmar-cuenta.html](confirmar-cuenta.html) |
| Reset password | `Recupera tu contraseña de MtiGo!` | [recuperar-contrasena.html](recuperar-contrasena.html) |
| Change email address | `Confirma tu nuevo correo en MtiGo!` | [cambiar-correo.html](cambiar-correo.html) |
| Magic link | `Tu enlace para ingresar a MtiGo!` | [enlace-magico.html](enlace-magico.html) |
